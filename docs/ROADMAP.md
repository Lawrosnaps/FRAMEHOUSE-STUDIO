# Framehouse Roadmap

## Phase 1 - Framehouse Stories Foundation

Goal:
Create a local story review system.

Features:
- Local backend API
- SQLite database
- Story data model
- Story status workflow
- Simple frontend dashboard
- Manual story creation
- Story list/review view

Statuses:
- new
- interesting
- approved
- rejected
- in_progress
- published
- archived

## Phase 2 - Basic Collectors

Goal:
Bring potential stories into the holding database.

Features:
- RSS/feed collector
- manual URL importer
- YouTube metadata importer
- basic web search/import workflow where legally and technically appropriate
- source type tagging
- duplicate detection

## Phase 3 - AI Story Triage

Goal:
Use AI to help decide what stories may be useful.

Features:
- AI-generated summary
- topic/category suggestion
- possible creator angle
- misinformation/context warning
- suggested format, e.g. short, explainer, reaction, long-form

## Phase 4 - Research Pack

Goal:
Turn approved stories into usable content prep.

Features:
- key facts
- timeline of events
- source links
- police powers/context notes
- opposing viewpoints
- risks/defamation/compliance notes
- script outline

## Phase 5 - Script and Shot Plan

Goal:
Help create the actual content.

Features:
- short-form script
- YouTube script
- voiceover draft
- hook options
- title options
- thumbnail ideas
- B-roll/media checklist

## Phase 6 - Media Bin

Goal:
Organise downloaded/imported media for each story.

Features:
- source videos
- stills
- screenshots
- thumbnails
- transcripts
- captions
- notes

## Phase 7 - Rough Cut Builder

Goal:
Generate a first draft edit.

Features:
- transcript-based selects
- clip ordering
- basic cuts
- captions
- music bed placeholder
- export to timeline format if needed

## Phase 8 - Framehouse Editor

Goal:
Build an all-in-one lightweight editor.

Features:
- timeline
- trimming
- captions
- audio levels
- simple motion graphics
- templates
- export presets
- platform-specific outputs

This phase may require Rust, C++ or a dedicated video engine. Do not start here.
