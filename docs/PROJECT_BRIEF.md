# Framehouse Project Brief

Framehouse is a creator operating system designed to help users discover, prepare, edit and publish video content faster.

The long-term goal is to replace the small but important part of Adobe Creative Cloud that many social/video creators actually use, while adding AI-powered discovery, research, scripting, rough-cut editing, motion graphics and export workflows.

Framehouse is not intended to compete with full Hollywood-grade editing suites at first. It is aimed at YouTube creators, social media creators, commentators, small brands, education channels and niche content publishers.

The target feel is:

CapCut on steroids, with a newsroom brain and an editing pipeline.

## Prototype Use Case

The first prototype is focused on UK policing content.

The system should help identify potential stories, videos, discussions, controversies, policy developments and public conversations around UK policing.

Examples include:

- viral police interaction videos
- police auditor videos
- claims of police brutality
- public order incidents
- changes to police powers
- policy white papers
- major police news
- misinformation around policing
- explainers on why police acted in a certain way
- humorous or serious UK policing content suitable for UK Cop Humour-style channels

The prototype should gather possible stories into a holding database so the user can manually review them before deciding whether to proceed.

## Long-Term Product

Eventually, Framehouse should support any user-defined niche.

Example niches:

- UK policing
- Minecraft
- Marvel
- football
- local news
- tech reviews
- business commentary
- true crime
- education

The user should be able to define their content niche, tone, sources, preferred angles and publishing formats.

Framehouse should then help them find potential content ideas, collect source material, generate research packs, draft scripts, create rough cuts, add captions/motion graphics and export platform-ready content.

## Core Principle

Framehouse should automate the boring parts while leaving editorial control with the user.

The user decides what is worth publishing.
The system helps them get there faster.
